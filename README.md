DELIVERY

- Velocity & Trends

RISKS
- Sprint Risk
- Flow Intelligence
- Blockers & Dependencies
- Recommendations

ENGINEERING
- Rework & Reopened
- Quality & Bugs
- Code & PR Intelligence
- Builds & Deployments

RELEASE
- Release Intelligence
- Release Readiness

AI COPILOT
- Ask Copilot
- Root Cause Analysis
- AI Recommendations

ANALYTICS
- Historical Trends
- Productivity
- AI Impact
- ROI

## Run in VS Code

1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Open the terminal.
4. Run:

   npm install

5. Then:

   npm run dev

6. Open the local Vite URL shown in the terminal.

The prototype currently uses mock data. The next step is to replace the mock data with FastAPI endpoints backed by Azure DevOps / Git / CI/CD data and your ML models.
